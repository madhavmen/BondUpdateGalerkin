# Canonical contributor standards

These files define the repository's engineering and scientific standards for developers and coding agents. The root `CLAUDE.md` loads short essential rules through `AGENTS.md`; it points to these detailed references when relevant. Specialized guidance is provided through `.claude/rules/` and repeatable procedural workflows through `.claude/skills/`.

- `architecture.md`: where code belongs, what depends on what, and how MPS/QTT share BUG.
- `code-quality.md`: Julia style, documentation, type stability, interfaces and error handling.
- `scientific-validation.md`: evidence required for algorithms, physics and PDE models.
- `testing.md`: unit, integration, regression, performance and release checks.
- `definition-of-done.md`: short mandatory finish checklist.

Do not grow this directory into an archive of daily notes. Long experiments, task plans, and generated plots belong elsewhere.
