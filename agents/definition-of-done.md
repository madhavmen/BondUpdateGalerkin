# Definition of done (required summary)

Before marking a task complete, confirm:

- [ ] Correct ownership folder and API boundary; no duplicate BUG implementations.
- [ ] Mathematical assumptions and tensor dimensions documented where relevant.
- [ ] Public docstrings and examples updated if behavior or API changed.
- [ ] Minimal unit test plus appropriate independent physics/PDE reference added or reviewed.
- [ ] Known behavior regressions explained; no hidden change in numerical signs, rank policy, or ordering.
- [ ] Relevant formatting, tests and static quality checks actually run; their results reported.
- [ ] No secrets, private paths, generated output or unlicensed assets added.
- [ ] Final response lists modified files, scientific impact, tests run/not run, and remaining risks.

If a check cannot be done, say why and record it as unfinished work. Never report checks as passing without executing or observing them.
